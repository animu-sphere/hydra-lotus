# v0.2.0 release gate

Verified on 2026-10-11 against `c29af24`, with the version bump, release
documentation and the new top-level `VERSION` file on top: CMake's
`project(Lotus VERSION)` now reads that file, and `scripts/release.py`
checks it against `openstrata.toml`. Renderer implementation, shaders and the
committed reference images were unchanged by release preparation; the
reference images are unchanged since v0.1.0. The
[Renderer Phase 2 exit review](2026-10-11-hydra-integrator-selection.md#renderer-phase-2-exit)
and the wavefront cost measurements it links are preserved. Release and
phase status belong in the
[canonical roadmap](../roadmap/README.md#status-at-a-glance).

## Required gate observations

- Both physical-GPU configurations rendered 1,000 deterministic bootstrap
  frames. Synchronization validation was enabled with no validation
  messages.
- The fixed Cornell scene at 1, 16, 64, 256 and 1024 spp passed the committed
  mean/variance tolerance under both integrators. The committed sample
  sequence reproduced the reference bit for bit, a 10% brighter red wall was
  rejected (maximum absolute z score 6.32), and the same 64 samples from both
  integrators were identical bit for bit. The coverage-before-scattering
  scenario matched the reference integrator's mean. References were not
  regenerated.
- The wavefront integrator's queue occupancy and kernel timings were
  recorded (core: 59,654 rays in 17 bounces, 6 of them as rounds;
  camera/intersect/shade/tail 0.012/0.045/0.042/0.030 ms of a 0.151 ms
  scene pass). This release verification does not claim a new timing
  baseline; the [camera and resolve report](2026-10-11-wavefront-camera-resolve.md)
  remains the cost evidence.
- Hydra discovery, delegate creation, CPU buffers, deterministic sample
  settings, integrator selection, lights, materials/textures/normals/opacity,
  instancing and render-pass selection passed. The usdview smoke test,
  including the *Wavefront integrator* menu toggle, passed.
- The standalone viewport's disposition remains the previously measured
  [foundation review](2026-10-10-foundation-closure.md); this session did
  not rerun the viewport.

## Package

Two `ost package --profile lookdev --intent hydra --json` invocations of the
validated Hydra build returned the same archive digest:

```text
sha256:1043dad25174cd54e5ddb4c5235817d83df16874ca1f9c9b8562b1d8825df001
```

The 1,301,244-byte archive has 30 manifest entries, including
`wavefront.comp.spv` beside the headless runner and the plugin.
`scripts/release.py stage` and `bundle` checked the package identity,
archive hash and required products, and assembled the source archive,
`SHA256SUMS` and notes under `build/release-v0.2.0-bundle`. The published
assets are rebuilt by the tag-driven workflow on the hosted runner; this
local bundle verifies the same helper path.
