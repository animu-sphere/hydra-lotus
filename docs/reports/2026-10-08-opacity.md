# Opacity coverage and alpha masks

Measured on 2026-10-08 in the working tree based on `9d4e4bf`, on Windows
x86_64 with MSVC 14.51, OpenStrata 0.23.14 and Release builds. The GPU was
an NVIDIA RTX A5000, Vulkan API 1.4.329. Hydra used OpenUSD 26.08 lookdev
and Python 3.13. All runs were local; hosted CI was not measured.

## Scope and policy

The next slice of
[Renderer Phase 1.5](../roadmap/current.md#renderer-phase-15--minimal-material-ir):
constant or scalar-textured `UsdPreviewSurface.opacity` and constant
`opacityThreshold`. A positive threshold selects binary cut-outs, accepting
equality. Threshold 0 selects stochastic **presence coverage**, scaling the
expected entire BSDF and emission by accepting each intersection with
probability opacity. Rejection passes the ray straight through.

This is the project's alpha policy, not a complete implementation of the
[UsdPreviewSurface specification](https://openusd.org/release/spec_usdpreviewsurface.html):
glass, refraction, absorption and `opacityMode` interpretation remain
unsupported. The current contract belongs in the
[scene reference](../reference/SCENE.md#materials-and-environment).

## Implementation

The material IR adds opacity (default 1), threshold (default 0) and a sixth
texture input. Constants are finite and in [0, 1]; scalar lookups reuse the
existing channel, wrap, scale, bias, fallback and texture-coordinate
translation. Evaluated finite opacity is clamped; non-finite lookup
arithmetic gives zero coverage. The GPU material record is 464 bytes.
Upload validation, texture resolution and readback include the new input.

Every BLAS uses non-opaque geometry, allowing one geometry to serve
different materials and coverage edits to leave its acceleration structure
intact. The ray query tests coverage before confirming a triangle
candidate. The no-duplicate-intersection build flag avoids retrying a
fractional test, following
[Vulkan ray traversal](https://docs.vulkan.org/spec/latest/chapters/raytraversal.html).
Rejected candidates consume no bounce, origin offset or throughput change.
The rule applies to primary and secondary rays. Masks and opacity endpoints
consume no RNG draws, preserving opaque reference sequences.

Depth and surface diagnostics use a fixed per-pixel coverage realization
at sample index 0. Radiance samples use the path RNG. Primary misses
contribute the clear background and secondary misses the environment.
With a transparent clear, colour alpha estimates primary coverage. No
target, dependency, pipeline or pass is added.

## Verification

**Core and GPU scene.** Core tests reject non-finite and out-of-range
opacity/threshold constants and invalid lookup channels. An opacity-only
lookup selects the mesh's UV set and resolves the sixth texture slot;
changing coverage rewrites only the material table. The headless upload
walk reads back opacity, threshold and the alpha-channel texture lookup.

**Masks.** `renderer.path.opacity` renders 64x64 orthographic views of
two emissive squares. At 4 spp, first sample index 0 and zero permitted
scattering events, opaque, zero coverage, threshold equality and below-
threshold surfaces show exact foreground or background emission.
Pixel-centre albedo and depth of an sRGB image's linear alpha mask match
the independent CPU bilinear oracle, including scale/bias, mirrored UVs
and texture replacement. Removing the image exercises its unscaled
fallback. A float image checks scalar channel selection, range clamping,
missing UVs and an overflowed alpha lookup that must reject the surface.

**Continuous coverage.** Absorbing emissive layers give analytic mixtures,
without reproducing the shader RNG. Each comparison uses 32 spp, first
sample index 0, at 64x64: 131,072 samples. Means must agree within five
standard errors estimated from the pixel means.

| Scene | Expected RGB | Measured RGB |
| --- | --- | --- |
| One layer, opacity 0.25, over an opaque background surface | `(1, 1.5, 0.75)` | `(1.0002, 1.4999, 0.7499)` |
| Two independent layers, opacity 0.25 and 0.5 | `(1, 0.75, 0.75)` | `(1.0002, 0.7511, 0.7488)` |
| A mirror's secondary ray through opacity 0.25 | `(1, 0, 1.5)` | `(1.0012, 0, 1.4994)` |

A lone opacity-0.25 surface checks primary alpha against the analytic
Bernoulli standard error and each pixel's exact background composition.
Changing the first sample index to 99 leaves depth unchanged; returning
to 0 reproduces colour and depth bit for bit after restarting accumulation.
A mirror sees an emissive wall through a cut-out outside the camera view:
with only one allowed scattering event, transparent and opaque cut-outs
give exact far-wall and near-wall emission at 4 spp, first sample index 0.

**Hydra.** `lotus-renderer-hydra-texture` and `-gpu` check clamped and
non-finite constants, shared alpha-image translation and rejection of RGB
on a scalar opacity connection. A stage uses a two-texel RGBA PNG mask,
with different foreground/background emission. At 1 spp, first sample
index 0, every pixel of its 8x8 AOV has exact expected emission and alpha
1. Image replacement reverses the mask without replacing geometry;
threshold edits retain the decoded image; a missing file uses unscaled
fallback at threshold equality; disconnecting opacity releases the lookup.
At 64 spp, constant opacity 0.25 matches the analytic layer mixture within
five Bernoulli standard errors across all 64 pixels.

**Reference regression.** The Cornell box passes at 1, 16, 64, 256 and
1024 spp and reproduces the committed reference sample sequence bit for
bit. Reference files were not regenerated. Vulkan validation reports zero
messages.

## Fault injections

Temporary shader copies were compiled and placed in the core executable's
shader directory. The original SPIR-V was restored in a `finally` block
and verified by SHA-256. Repository shader sources were not changed for
these injections. Both headless runs exited 1 and failed
`renderer.path.opacity`:

| Fault | Detected result |
| --- | --- |
| Confirm every candidate without testing opacity | Zero-coverage foreground emits red 4 instead of background red 0 |
| Use opacity squared as acceptance probability | One-layer red mean 0.249634 instead of 1, tolerance 0.013350 |
