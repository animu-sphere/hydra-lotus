Verified on 2026-10-18 against `f58ece0`, with the LOTUS-VIEWPORT-04 change,
the version bump and release documentation on top. The renderer's shaders
and the committed reference images are unchanged since v0.5.1 except for the
GPU reservoir first-candidate fix shipped with
[LOTUS-VIEWPORT-03](2026-10-18-viewport-controls.md#findings-fixed-on-the-way).
Phase/release status stays in the
[canonical roadmap](../roadmap/README.md#status-at-a-glance).

A5000 (driver 597.16) and Vulkan loader 1.4.321. Hydra uses the adopted OpenUSD
26.08 lookdev runtime with Python 3.13. GPU clocks were not locked; no timing

## Gate observations

- The physical-GPU suite reports no failed or skipped renderer assertions.
  Synchronization validation is enabled with no validation messages.
  Deterministic reference images, CPU/GPU reservoir arithmetic, visibility,
  lifecycle, the emissive and Hydra reset contracts and every headless
  comparison workload pass under both integrators. Committed references are
  unchanged since v0.4.0.
- The installed usdview check passed in 110.38 seconds.
- A first run of the gate stopped when the host restarted during
  `lotus-renderer-restir-gpu`, after 40 entries had passed; the results above
  are from a complete rerun.
- The viewport is outside the Hydra package and `ost validate`'s durable
  launch check. Its GPU tests ran in the viewport trees for its
  [timing report](2026-10-18-viewport-timing.md#regression), where two of
  them lost the device at the second frame once and passed on rerun.

## Repeatable package

Two `ost package --profile lookdev --intent hydra --json` invocations
returned the same archive digest:

```text
sha256:99cdd09f8c540b3792a0a59961458b3f72be2388d031a55d48c36fafbc20b800
```

The 2,992,827-byte archive has 36 manifest entries. The
`scripts/release.py stage` command verified package/version/target identity,
digest agreement, the actual archive hash, SBOM identity and required
products, including shaders beside both the headless runner and Hydra
plugin, reference images and licensed validation assets. Staged assets are
under `build/release-v0.5.2-bundle`; tag-driven Actions rebuild the published
package on the hosted runner.

## Scope disposition

The [release record](../releases/v0.5.2.md) defines the shipped scope:
[step 2](../roadmap/current.md#step-2--viewport-foundation) of the v0.6.0
plan, the standalone viewport's foundation, shipped ahead of the denoiser.
The viewport is not in the Hydra package; its evidence is the
[presentation](2026-10-17-viewport-presentation.md),
[camera](2026-10-17-viewport-camera.md),
[controls](2026-10-18-viewport-controls.md) and
[timing](2026-10-18-viewport-timing.md) reports, whose intermittent
