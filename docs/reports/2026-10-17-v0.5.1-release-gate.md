# v0.5.1 release gate

Verified on 2026-10-17 against `6705c61`, with the Renderer Phase 5 exit
review, the version bump and release documentation on top. Renderer, backend
and shader sources and the committed reference images are unchanged since
v0.5.0; the changes since then are in the headless comparison harness, tests
and scripts. Phase/release status stays in the
[canonical roadmap](../roadmap/README.md#status-at-a-glance).

## Environment and commands

Windows 11 x86_64, MSVC 14.51, OpenStrata 0.23.14, Release, NVIDIA RTX
A5000 (driver 597.16) and Vulkan 1.4.329. Hydra uses the adopted OpenUSD
26.08 lookdev runtime with Python 3.13. GPU clocks were not locked; no timing
claim is derived from this gate.

## Gate observations

- The physical-GPU suite reports no failed or skipped renderer assertions.
  Synchronization validation is enabled with no validation messages.
  Deterministic reference images, CPU/GPU reservoir arithmetic, visibility,
  lifecycle, the emissive and Hydra reset contracts and every headless
  comparison workload pass under both integrators. Committed references are
  unchanged since v0.4.0.
- The installed usdview check passed in 106.20 seconds.
- The viewport retains its accepted
  [foundation disposition](2026-10-10-foundation-closure.md); it is not
  rerun for this release.

## Repeatable package

Two `ost package --profile lookdev --intent hydra --json` invocations
returned the same archive digest:

```text
sha256:020065c11df072667282cb012dbfb9b95ac3ea97d627a4ec9b14d4bbf1d27a84
```

The 2,958,134-byte archive has 34 manifest entries. The
`scripts/release.py stage` command verified package/version/target identity,
digest agreement, the actual archive hash, SBOM identity and required
products, including shaders beside both the headless runner and Hydra
plugin, reference images and licensed validation assets. Staged assets are
under `build/release-v0.5.1-bundle`; tag-driven Actions rebuild the published
package on the hosted runner.

## Scope disposition

The [release record](../releases/v0.5.1.md) defines the shipped scope. The
[Renderer Phase 5 exit review](2026-10-17-renderer-phase5-exit.md) closes the
phase on its exit criteria: NEE/MIS remains the default renderer path,
initial-only reservoirs with eight candidates are recommended only for many
lights of similar importance, and ReSTIR stays opt-in with settings unchanged
from v0.5.0.
