  Synchronization validation is enabled with no validation messages.
  Deterministic reference images, independent lighting/BSDF checks,
  CPU/GPU reservoir arithmetic, visibility, lifecycle, resets and benchmark
  contracts pass under both integrators. Committed references are unchanged
  since v0.4.0.
- The installed usdview check passed in 116.04 seconds. Its 903 frame

- The latest implementation's hosted
  [renderer CI](https://github.com/animu-sphere/hydra-lotus/actions/runs/38892532039)

  [foundation disposition](2026-10-10-foundation-closure.md); it is not
  rerun for this experimental release.

## Repeatable package

Two `ost package --profile lookdev --intent hydra --json` invocations
returned the same archive digest:

```text
sha256:f3e2d3f35a1d4b31a2327133acfe42dae8be6455f46b6153e27a51506c0bbb52
```

The 2,941,875-byte archive has 34 manifest entries. The
`scripts/release.py stage` command verified package/version/target identity,
digest agreement, the actual archive hash, SBOM identity and required
products, including shaders beside both the headless runner and Hydra
plugin, reference images and licensed validation assets. Staged assets are
under `build/release-v0.5.0-bundle`; `scripts/release.py bundle` adds source
from the committed release preparation, checksums and notes. Packaging ran
while the remaining regression benchmarks were in progress; no source or
shader changes occurred, and no performance claim is derived from that run.
Tag-driven Actions rebuild the published package on the hosted runner.

## Scope disposition

The [release record](../releases/v0.5.0.md) defines the shipped experimental
snapshot and compatibility. ReSTIR stays opt-in and progressive NEE/MIS
remains the default. Initial, temporal, spatial and combined modes, proposal
strategies, Hydra controls/AOVs and bounded comparisons are included.

The [rough dielectric/sphere-light measurements](2026-10-16-restir-glossy-spheres.md)
report increased static temporal-reuse error, temporal residual correlation
and no repeatable combined equal-quality speedup. The
[complementary BSDF partition](2026-10-16-restir-bsdf-partition.md) improves
the reproduced narrow-glossy gap but does not resolve general bias/artifact,
multibounce, convergence or performance questions. These remain explicit
release limitations and active work; this release makes no phase-exit claim.
