# Material basics fixture

## Evaluation brief

LOTUS-MATERIAL-01, first slice. The
[workstream contract](../design/ROADMAP_POLICY.md#practical-foundation-workstreams)
asks for representative USD fixtures, reference images and Hydra/headless
consistency, audited in a fixed order. This slice establishes that
mechanism and audits the first two items, base colour and
metallic/roughness, against the
[material contract](../reference/SCENE.md#materials-and-environment), the
[Hydra translator](../reference/SCENE.md#materials) and the
[capability matrix](../reference/CAPABILITY_MATRIX.md).

The fixtures are authored in this repository rather than imported from
third-party assets: they carry no licence obligations, and every authored
value has a known expected translation. Real-asset gaps may still need
imported assets later.

The mechanism has four parts, described in the
[scene reference](../reference/SCENE.md#material-fixtures):

- a committed `UsdPreviewSurface` stage, `validation/materials/material-basics-v1.usda`,
  generated by `scripts/material_fixtures.py`, which fails its check and
  unit test when the committed file is stale;
- an independent C++ mirror (`adapters/common/material_fixtures.cpp`) of
  what the translator should extract, written from the contract, not from
  the translator;
- committed Reference PT images of the mirror (4096 spp mean and
  per-sample variance) and the headless check `renderer.material.fixtures`;
- the Hydra CTests `lotus-renderer-hydra-material-fixtures` (snapshot
  against the mirror) and its `-gpu` variant (Hydra's image against the
  mirror's and the reference).

Adopt the mechanism if the stage extracts to the mirror, every rendered
mode matches the reference by the
[DES-Q5 metric](../reference/SCENE.md#reference-images), and the metric
rejects a 10% base-colour change on one ball. Textures/UV, normal maps,
emission and alpha masks are later slices; the viewport, temporal/SVGF
modes and performance are not covered. This slice adds no shader path.

Conditions: Windows AMD64, MSVC 19.51 Release, NVIDIA RTX A5000, driver
597.16, Vulkan 1.4.329, validation and synchronization validation active,
clocks unlocked. Source `e1c641f` plus this change. The binaries' hashes,
the reference's hashes and every value are in the
[data](2026-10-26-material-basics.json).

## Fixture

`material-basics-v1` is a 4×4 grid of authored-normal spheres in front of
an unbound backdrop, under a dome and a rect key light, at 128×128. Its rows
cover base colours (including an out-of-range colour and roughness),
dielectric roughness 0 to 1, metal roughness 0 to 1, and partial metallic,
a metallic-workflow ior and the specular workflow with ignored metallic and
ior. The [scene reference](../reference/SCENE.md#material-fixtures) lists
every authored value.

The reference was written with
`lotus-headless --write-material-reference validation/reference` in
4.5 seconds: 64 batches of 64 samples, then 4096 samples in one
accumulation, BSDF sampling, from sample index 0.

## Audit

| Item | Contract | Evidence | Finding |
| --- | --- | --- | --- |
| `diffuseColor` | Clamped to [0, 1] | Clamped's (1.25, 0.5, −0.25) extracts as (1, 0.5, 0) | As documented |
| `displayColor` fallback | Constant colour of an unbound mesh as base colour | The backdrop's private material `…/Backdrop.lotus:displayColor` | As documented |
| `roughness` | Clamped to [0, 1]; GGX alpha is its square | 1.5 extracts as 1; rows at 0, 0.25, 0.5 and 1 | Roughness 0 renders with alpha 10⁻³, a near-mirror, which the contract did not state; now documented |
| `metallic` | Clamped; metal fraction over a dielectric | Metal row at 1; 0.25 and 0.75 | As documented |
| `ior` | Read in the metallic workflow | Ior25 extracts with ior 2.5 | As documented |
| Specular workflow | `specularColor` replaces F0; metallic 0; ior not read | Specular's authored metallic 1 and ior 3 extract as 0 and 1.5 | As documented |
| Not read | `clearcoat`, `clearcoatRoughness`, `occlusion`, `displacement`, `opacityMode` | Not authored | Unchanged; already listed as not read |

No behaviour defect was found in base colour or metallic/roughness. The
roughness floor was a documentation gap; the material contract's table
now states it.

## Results

**Extraction.** UsdImaging's snapshot of the stage equals the mirror's
exactly: materials, bindings, triangles, lights and environment compare
equal, and no transform, camera, position or normal set differs even by
rounding. The CTest allows 2·10⁻⁶ for those but did not need it.

**Images against the reference** (sample index 2²⁰, 8-pixel tiles):

| Mode | spp | Image z (R, G, B) | Max tile \|z\| | Mean tile z² |
| --- | ---: | --- | ---: | ---: |
| Reference integrator, BSDF | 16 | −1.37, −0.65, −0.48 | 3.01 | 0.99 |
| Reference integrator, BSDF | 256 | −0.48, −0.11, 0.57 | 3.22 | 0.94 |
| Reference integrator, NEE/MIS | 16 | 0.64, 0.79, 0.76 | 2.67 | 0.23 |
| Reference integrator, NEE/MIS | 256 | 0.26, 0.09, −0.08 | 2.07 | 0.27 |
| Wavefront integrator, NEE/MIS | 16 | 0.64, 0.79, 0.76 | 2.67 | 0.23 |
| Wavefront integrator, NEE/MIS | 256 | 0.26, 0.09, −0.08 | 2.07 | 0.27 |
| Hydra, NEE/MIS | 256 | 0.26, 0.09, −0.08 | 2.07 | 0.27 |
| Hydra, BSDF | 256 | −0.48, −0.11, 0.57 | 3.22 | 0.94 |

The wavefront images are byte-identical to the reference integrator's, and
each Hydra image is byte-identical to the backend's image of the mirror
with the same settings, which the `-gpu` CTest now requires. NEE/MIS has
lower variance than the BSDF-sampling reference that sets the metric's
standard errors, so its mean z² near 0.25 shows the metric is conservative
for it, as for the Cornell box.

**Power and reproducibility.** The half-rough metal's base colour 10%
darker is rejected at max tile |z| 14.85 at 256 spp. Re-rendering the
reference's own samples reproduces the committed mean bit for bit on this
device and build.

**Cost.** The headless evidence CTest, which includes the new check, took
37.5 s. The check renders about 5,100 spp at 128×128, about 3 s by
proportion with the reference write; it was not timed separately. The
Hydra CTests took 0.06 s (CPU) and 11.6 s (GPU).

## Decision

Adopted: the fixture mechanism and `material-basics-v1`. Base colour and
metallic/roughness need no renderer or translator fix; the roughness-0
floor is now documented.

## Next items

Following the audit order: textures and UV (wrap modes, colour spaces,
texture-coordinate sources, the untranslated `UsdTransform2d`, and
minification without mipmaps), then shading normals and normal maps,
emission and alpha masks, each as a fixture beside this one.

## Unavailable and unmeasured

- The reference is a finite 4096-spp estimate, not ground truth; agreement
  is statistical except where stated byte-identical.
- Bit-for-bit reference reproduction holds on this device, driver and
  build only.
- The viewport, usdview and the installed Hydra host were not run with the
  fixture. `ci-core` and the other Hydra CTests were not rerun; only the
  evidence, assets, install-tree and test-tier CTests and the two new
  Hydra CTests ran.
- Third-party production assets were not audited.
