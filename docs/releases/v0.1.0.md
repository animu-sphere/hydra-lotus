# v0.1.0 — Foundation release

Released on 2026-10-10 under Apache-2.0. This first source release provides
a deterministic Vulkan reference path tracer for OpenUSD Hydra, with
minimal materials/textures, incremental scene extraction and a measured
backend. It includes the implemented Renderer Phase 0, Renderer Phase 1
and Renderer Phase 1.5 scope; version numbering follows delivered milestones.

## Shipped capabilities

- Host-neutral scene/world and extraction targets, a Vulkan backend, the
  `lotus-headless` runner, the `hdLotus` Hydra delegate and a standalone
  bootstrap viewport, with CMake install/export support.
- Ray-query path tracing with Lambert, GGX metal and dielectric reflection,
  emission, constant environments/dome lights, multiple bounces, Russian
  roulette and HDR accumulation. Fixed sample indices reproduce the
  committed Cornell reference; Hydra exposes the same deterministic control.
- Hydra coarse meshes, authored/computed normals, instancing, dirty updates,
  visibility and render-pass selection, cameras, color/depth AOVs and
  restoration when a bound AOV has no clear value.
- Minimal `UsdPreviewSurface` translation, material bindings and
  `displayColor` fallback, image textures/UV sets, normal maps, opacity
  coverage and alpha masks.
- Incremental GPU uploads, pooled scene memory, compatible BLAS point refits
  and TLAS updates, plus GPU timestamps and a fixed four-workload benchmark
  that records raw measurements and explicitly unavailable metrics.
- Documentation and dependency-boundary CI, runtime-free operation,
  explicit capability SKIPs and synchronization-validation regressions.

Detailed changes are in the [changelog](../../CHANGELOG.md#010---2026-10-10).
The [release-gate report](../reports/2026-10-10-release-gate.md) records the
checks, [foundation review](../reports/2026-10-10-foundation-closure.md)
records scope dispositions, and the
[performance baseline](../reports/2026-10-10-performance-baseline.md)

## Compatibility and delivery

This release is distributed as source through the `v0.1.0` Git tag and
GitHub source archives. Build and install with the repository's
[building guide](../guides/BUILDING.md). No prebuilt runtime or renderer
binary is included.

Measured configuration: Windows 11 x86_64, MSVC 14.51, OpenStrata 0.23.14,
NVIDIA RTX A5000 and OpenUSD 26.08/Python 3.13 for Hydra. The default core
build does not require OpenUSD; the Hydra adapter requires a matching imaging
runtime. GPU scene rendering requires Vulkan 1.3, Slang and the ray-query,
acceleration-structure and shader features listed in the
[configuration reference](../reference/SUPPORTED_CONFIGURATIONS.md#requirements).
Unavailable GPU support reports explained SKIPs rather than physical-GPU
validation success.

## Known limitations at release

- The standalone viewport presents the bootstrap triangle. The offscreen
  renderer has one frame in flight and blocking CPU readback.
- Hydra ID channels are CPU sentinels; picking is unavailable.
- Light transport uses brute-force reference sampling. Explicit direct-light
  sampling/NEE/MIS, Wavefront transport, ReSTIR, temporal reconstruction,
  denoising and spectral rendering are outside this snapshot.
- Material and texture translation is a minimal subset. Production
  MaterialX/OpenPBR, glass/transmission and broader light/scene coverage
  are outside this snapshot.
- Linux, macOS and AMD/Intel GPUs have not been measured. Japanese MSVC
  dependency discovery and OpenStrata workflow/runtime-free validation
  selection require the documented workarounds.

The precise shipped constraints and rationales are recorded in the
[configuration limitations](../reference/SUPPORTED_CONFIGURATIONS.md#foundation-bootstrap-limitations),
[scene/material reference](../reference/SCENE.md) and
[AOV contract](../reference/AOVS.md). Future implementation work is tracked
in the [active roadmap](../roadmap/current.md).
