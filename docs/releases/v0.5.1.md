# v0.5.1 — Renderer Phase 5 closure release

Released on 2026-10-17 under Apache-2.0. This patch release closes the
ReSTIR DI investigation on its exit criteria and records the decision:
progressive NEE/MIS stays the default renderer path, and direct-light
reservoirs are one selectable transport mode with a measured place to use
them. The renderer, shaders and Hydra plugin behave as in
[v0.5.0](v0.5.0.md); this release adds measurement harness, tests and
evidence. Ongoing scope and release targets remain in the
[canonical roadmap](../roadmap/README.md#status-at-a-glance).

## Decision shipped

The [exit review](../reports/2026-10-17-renderer-phase5-exit.md) records, per
representative workload, whether reservoirs reach equal quality faster, with
the known bad cases, correlation cost and unsupported conditions. Timings come
from [locked GPU clocks](../reports/2026-10-17-restir-reuse-cost.md):

- **NEE/MIS is the default** under both integrators, headless and through
  Hydra. With area lights, an environment, glossy materials or deep
  interreflection no reservoir mode reaches equal quality faster.
- **Initial-only reservoirs with eight candidates** (`lotus:restir` on, reuse
  off) are worth using for many lights of similar importance that BSDF
  sampling cannot find: about 1.4 times faster to equal quality with many
  distant lights, accumulating and in motion, with no history.
- **Temporal, spatial and combined reuse** are not worth using as a renderer
  path. Their value as denoiser input is left to the denoiser.

The [reservoir reference](../reference/RESTIR.md#when-to-use-reservoirs) owns
this guidance; ReSTIR DI now gains no new fixtures.

## Shipped capabilities

- Headless ReSTIR comparison workloads and statistics added since v0.5.0:
  configurable scattering depth and reference seed, across-sequence ensemble
  decomposition, replication bias tests per pose, band and 8x8 tile, a closed
  interreflecting room, and stepped light/material animation with exact
  reset checks.
- Reset-contract tests for emissive emission, toggle, visibility and placement
  edits in the core, and USD light, material, emission, placement and
  visibility edits through Hydra, under both integrators.
- `scripts/restir_campaign.py`, a resumable runner for JSON plans of headless
  comparisons; timing evidence requires serial runs and locked clocks.
- ReSTIR CTest checks run in parallel, shortening the managed core suite.

Detailed changes are in the [changelog](../../CHANGELOG.md#051---2026-10-17);
the [release gate](../reports/2026-10-17-v0.5.1-release-gate.md) records
verification.

## Correctness and measurement

No bias, ghosting or localized error attributable to reuse was found in the
bounded fixtures: [static ensembles](../reports/2026-10-16-restir-sequence-ensemble.md),
[four moving suites](../reports/2026-10-17-restir-moving-bias.md), a
[closed four-bounce room](../reports/2026-10-17-restir-interreflection.md) and
[light/material animation](../reports/2026-10-17-restir-animation.md). The
[reset contract](../reports/2026-10-17-restir-reset-contract.md) holds for
emissive-state edits and through Hydra, byte-identically under both
integrators. These bound, rather than establish, unbiasedness.

## Compatibility and delivery

The `v0.5.1` tag publishes the Windows x86_64 CY2026 lookdev/Hydra package
`lotus-0.5.1-cy2026-windows-x86_64-py313-lookdev--hydra.tar.zst`, its manifest
and SPDX SBOM, `hydra-lotus-0.5.1-src.tar.gz` and `SHA256SUMS` through the
[release workflow](../guides/RELEASING.md). The binary package requires
matching OpenUSD 26.08/Python 3.13 and Vulkan runtimes.

Measured configuration: Windows 11 x86_64, MSVC 14.51, OpenStrata 0.23.14,
NVIDIA RTX A5000 and OpenUSD 26.08/Python 3.13 for Hydra. Other configurations
build from source with the [building guide](../guides/BUILDING.md).

Settings, records, Hydra controls and AOVs are unchanged from v0.5.0, and
ReSTIR stays disabled by default. Headless comparison reports gain fields;
existing fields keep their meaning.

## Known limitations at release

- Reservoirs light only the primary surface; there are no indirect
  reservoirs. History is valid within one light-table generation, so any edit
  in a scene with emissive triangles resets it, and light slots are not
  remapped.
- Temporal reuse correlates frames (lag-one up to 0.69), and every reset
  replays the fresh batch's random numbers, correlating reuse noise about 0.58
  across edits ([DES-Q7](../design/DESIGN_POLICY.md#53-open-questions), to be
  decided with the denoiser).
- Reuse frames read back and check evidence products, 28–36 ms of wall time at
  128x128, so reuse is not interactive as it stands.
- Cost is measured on one GPU at one locked clock, up to 256x256 and 256
  lights, without emissive-mesh or production scenes; every ray still tests
  every analytic light.
- Denoising, GI reservoirs, production material expansion and light
  acceleration remain later work. The viewport still presents the bootstrap
  triangle; readback is blocking, Hydra ID channels remain clear sentinels,
  and Linux, macOS and AMD/Intel GPUs are unmeasured.

The full list of bad cases and unsupported conditions is in the
[exit review](../reports/2026-10-17-renderer-phase5-exit.md#unsupported-conditions);
remaining work is in the [active roadmap](../roadmap/current.md).
